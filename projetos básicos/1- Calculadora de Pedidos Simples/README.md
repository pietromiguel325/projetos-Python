# 🛒 Desafio 1: Calculadora de Pedidos Simples

Um script em Python concebido para processar uma lista de pedidos de vendas, calcular o total acumulado do faturamento e identificar o pedido de maior valor.

---

## 📌 Funcionalidades

- **Cálculo por Pedido**: Calcula o valor total de cada item multiplicando a quantidade pelo preço unitário.
- **Acumulador de Faturamento**: Soma os totais de todos os pedidos para obter o faturamento geral.
- **Destaque de Maior Pedido**: Identifica e exibe o pedido com o maior valor total utilizando a função `max()` em conjunto com expressão `lambda`.

---

## 💻 Tecnologias e Conceitos Utilizados

- **Python 3**
- **Estruturas de Dados**: Listas e Dicionários (`list` de `dict`).
- **Funções Personalizadas**: Definição e reutilização de funções (`def`).
- **Expressões Lambda & Parâmetro `key`**: Para comparação e ordenação dinâmica de dicionários.
